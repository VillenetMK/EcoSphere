## Regla de actualización

No convertir una observación visual, recomendación de compra o valor inicial de firmware en dato confirmado. Toda corrección física debe registrar:

- evidencia: etiqueta, continuidad, tensión, corriente o prueba funcional;
- fecha;
- valor anterior;
- valor confirmado;
- cambio correspondiente en firmware, contrato y pruebas cuando aplique.

Las credenciales Wi-Fi nunca se documentan ni versionan.
